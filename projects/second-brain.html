Second Brain

A personal knowledge base you can talk to. Feed it PDFs, notes, code, web pages and YouTube videos, then ask questions and get answers that cite their sources.

01Overview

Second Brain pulls PDFs, Markdown, DOCX, code files, web pages, YouTube transcripts, Notion pages and Obsidian vaults into one local index, and lets you ask questions about all of it in plain language.

Every answer comes back with citations to the chunks it was built from, so you can check what the model is relying on. The same index is exposed as an MCP server, so Claude Desktop can search your notes in the middle of a conversation.

02How it works

  1. 01Ingest

    Files, folders, URLs, YouTube and Notion

  2. 02Chunk & embed

    512-token chunks, local sentence-transformers or OpenAI

  3. 03Index

    Qdrant for vectors, SQLite FTS5 for keywords

  4. 04Retrieve

    Hybrid semantic and keyword search

  5. 05Re-rank

    A cross-encoder picks the top 5 chunks

  6. 06Answer

    Claude responds with source citations

03Features

  • Hybrid retrieval

    Vector and keyword results are merged, then re-ranked by a cross-encoder model.

  • Cited answers

    Every response links back to the exact source chunks it used.

  • MCP server

    Claude Desktop gets search_brain, add_document, list_sources and delete_source as tools.

  • Watch folder

    Drop files into an inbox folder and they are ingested automatically.

  • Web UI and CLI

    Add and remove sources from the sidebar, or chat straight from the terminal.

  • Local embeddings by default

    A free offline embedding model out of the box; OpenAI embeddings are optional.
