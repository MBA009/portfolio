MARQUEE

Type in a movie title and MARQUEE predicts its worldwide box-office gross. It scrapes its own features from five public sources, so it needs no API keys.

01Overview

MARQUEE is an end-to-end ML system: a scraper, a model and a web UI. You enter a title, review the features it found and fill in anything missing, then run the prediction to get an estimated gross, a confidence interval and a chart of which features pushed the number up or down.

The model is a gradient-boosted regressor (500 trees, depth 4) trained on a log-transformed target. It is currently trained on 6,000 synthetic films.

04Robustness

  • Fails soft

    Every field is scraped independently, so one broken source never fails a search.

  • Polite scraping

    Each request gets two retries with back-off delays.

  • Always predicts

    Missing features are median-imputed and marked "ESTIMATED" in the UI.

  • Fast restarts

    The first launch trains the model in about 15 seconds; later starts load the cached bundle.
