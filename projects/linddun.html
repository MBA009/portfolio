01Overview

LINDDUN is a privacy threat modeling framework, the privacy counterpart to STRIDE. Doing it by hand means walking every element of a data flow diagram through seven threat categories. This tool automates that pass with retrieval-augmented generation over the LINDDUN methodology and the regulations a system is checked against.

The knowledge base is built from official LINDDUN material (threat trees, LINDDUN GO and PRO), GDPR articles, COPPA, CCPA and the NIST Privacy Framework. The whole pipeline is also exposed as an MCP server, so Claude Desktop can run an analysis mid-conversation.

02How it works

  1. 01Bootstrap

    Embed LINDDUN, GDPR, COPPA, CCPA and NIST sources

  2. 02Describe

    Plain text, DFD elements, a guided form or a DFD image

  3. 03Retrieve

    Hybrid RAG search for each category

  4. 04Analyze

    Claude generates threats category by category

  5. 05Report

    Severity, risk score, citation and mitigation, exportable as JSON

04Output

  • Severity summary

    Threat counts by Critical, High, Medium and Low.

  • Filterable threat table

    Filter by category or severity; each card expands to the full description, mitigation and likelihood × impact score.

  • Regulatory citations

    Each threat is tied to a specific article, e.g. GDPR Art. 5(1)(b).

  • MCP tools

    analyze_privacy_threats, get_linddun_info and search_linddun_kb for Claude Desktop.
